# Function

## Definition
*함수* $f$는 다음과 같은 [[Tuple|튜플]] $(X,Y,graph⁡f)$

## Intuition
어떤 입력을 넣었을 때 정해진 방식으로 결과를 돌려주는 장치
하나의 입력에는 하나의 출력이 대응
![[Pasted image 20260923023718.png|241]]
> 함수는 입력값에 따라 출력값을 만들어 내는 ‘블랙 박스’와 같다.

## Mathematical Definition
함수는 보통 다음과 같이 표현
$$
f: X \rightarrow Y, \qquad y=f(x)
$$

## Example
$$f(x)=2x+1$$
에서 $x=3$이면 $f(3)=7$
