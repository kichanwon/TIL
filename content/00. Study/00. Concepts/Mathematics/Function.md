# Function

## Definition

함수(Function)는 입력값을 출력값에 대응시키는 규칙이다.

## Intuition

함수는 어떤 입력을 넣었을 때 정해진 방식으로 결과를 돌려주는 장치다. 하나의 입력에는 하나의 출력이 대응해야 한다.

## Mathematical Definition

함수는 보통 다음과 같이 표현한다.

$$
f: X \rightarrow Y, \qquad y=f(x)
$$

## Example

$$f(x)=2x+1$$

에서 $x=3$이면 $f(3)=7$이다.

## Applications in AI

머신러닝 모델은 입력 데이터를 예측값으로 변환하는 복합 함수로 볼 수 있다. 신경망의 각 층과 활성화 함수도 함수의 합성으로 표현된다.
