 아래처럼 WildDepth 기반 조류 거리추정 모델을 단계적으로 개발하는 계획을 추천합니다.

 1. 문제 정의

 ### 1차 목표

 - 입력: RGB 영상의 한 프레임
 - 출력:
     1. 조류 영역의 metric depth map
     2. 카메라에서 조류까지의 거리(m)
     3. 예측 신뢰도

 거리 정의는 혼동을 피하기 위해 다음 중 하나로 고정합니다.

 - 조류 마스크 내부 LiDAR 점들의 3D 거리 중앙값
 - 조류 중심점까지의 카메라 좌표계 Z 거리

 추천은 첫 번째입니다. 조류의 자세 변화에 더 안정적입니다.

 2. 데이터 범위 확인

 WildDepth에서 조류 관련 데이터는 공개 설명 기준으로 다음과 같습니다.

 - Bubye Valley Part 2: Three-banded plover bird
 - Kgalagadi: 대형 조류 포함
 - Longleat: Ostrich 포함 가능

 처음에는 데이터가 비교적 명확한 Bubye Valley Part 2로 MVP를 만드는 것이 좋습니다. 해당 다운로드는 약 38GB이며, plover 영상도 포함되어 있습니다.

 먼저 수행할 작업:

 - RGB 영상, LiDAR, depth map, calibration 파일 구조 확인
 - RGB-LiDAR timestamp 동기화
 - LiDAR를 RGB 좌표계로 투영
 - 조류 영역의 유효 LiDAR 점 개수 계산
 - LiDAR 점이 너무 적은 프레임 제외 또는 별도 표시
 - 데이터 라이선스와 공개 사용 조건 확인

 3. 데이터셋 구성

 조류 탐지·분할 라벨이 충분하지 않다면 다음 방식으로 만듭니다.

 4. SAM2 또는 조류 검출기로 초기 마스크 생성
 5. 일부 프레임을 수동 검수
 6. 영상 단위 tracking으로 연속 마스크 생성
 7. 조류 마스크 안에 투영된 LiDAR 점만 depth 정답으로 사용

 프레임 단위 랜덤 분할은 금지합니다. 같은 영상의 인접 프레임이 train/test에 섞이면 성능이 과대평가됩니다.

 추천 분할:

 - Train: 영상 단위 70%
 - Validation: 영상 단위 15%
 - Test: 영상 단위 15%
 - 추가 평가: 특정 영상 또는 환경을 통째로 제외하는 leave-one-video-out 평가

 4. 베이스라인

 다음 순서로 비교합니다.

 ### Baseline A: 사전학습 모델

 - Depth Anything 계열
 - DPT
 - Depth Pro

 WildDepth 논문에서는 DepthAnything이 비교 모델 중 가장 좋은 성능을 보였습니다.

 ### Baseline B: RGB 단안 depth fine-tuning

 - RGB만 입력
 - LiDAR는 학습 정답으로만 사용
 - 조류 마스크 내부의 sparse depth에 대해서만 loss 계산

 ### Baseline C: 거리 직접 회귀

 - 조류 crop을 입력
 - 조류까지의 거리 하나를 직접 예측
 - Depth map 방식과 비교

 초기에는 depth map을 예측한 뒤 마스크 내부 depth를 집계하는 방식을 주력으로 삼는 것이 좋습니다. 직접 거리 회귀보다 결과를 시각화하고 오류를 분석하기 쉽습니다.

 5. 제안 모델

 ### 입력

 - 원본 RGB 프레임
 - 조류 bounding box 또는 segmentation mask
 - 조류 주변 배경을 포함한 crop
 - 가능하면 1024px 이상의 고해상도 입력

 ### 구조

 - Depth Anything encoder 초기화
 - metric depth decoder 추가
 - mask-aware depth loss
 - 선택적으로 distance regression head 추가

 ### 손실 함수

 - 유효 LiDAR 점에 대한 log-L1 또는 BerHu loss
 - 조류 영역 가중치 loss
 - 인접 비디오 프레임 간 temporal consistency loss
 - 선택적 경계 보존 loss

 LiDAR가 희소하므로 전체 이미지 loss보다 조류 ROI와 유효 LiDAR 점 중심의 loss가 적절합니다.

 6. 평가 지표

 ### Depth 성능

 - RMSE
 - AbsRel
 - SILog
 - δ < 1.25

 ### 거리 성능

 - MAE(m)
 - RMSE(m)
 - Median Absolute Error
 - 상대 오차(%)
 - 10%, 20% 이내 예측 비율

 ### 반드시 나눠서 분석할 조건

 - 거리 구간별: 근거리 / 중거리 / 원거리
 - 조류 크기
 - LiDAR 점 개수
 - 조류 가림 정도
 - 조명과 배경
 - stationary / mobile 촬영
 - 학습 환경과 다른 환경

 7. 시간 순서

 ### 1주차: 데이터 감사

 - 파일 구조와 calibration 파싱
 - RGB-LiDAR 정렬 시각화
 - 조류 프레임 및 유효 depth 통계 작성

 ### 2주차: 전처리 파이프라인

 - 마스크 생성·검수
 - sparse depth map 생성
 - 영상 단위 train/validation/test split 구축

 ### 3주차: 베이스라인

 - 사전학습 Depth Anything 추론
 - RGB fine-tuning
 - ROI 거리 계산 코드 구현

 ### 4주차: 제안 모델

 - 고해상도 crop 기반 metric depth 모델
 - mask-aware loss
 - confidence output

 ### 5주차: 시간 정보 및 일반화

 - temporal smoothing
 - 영상 단위 평가
 - 다른 지역 또는 종에 대한 cross-domain 평가

 ### 6주차: 분석 및 정리

 - baseline 대비 성능 비교
 - 실패 사례 시각화
 - 모델 및 데이터 처리 재현성 정리

 8. 주요 위험 요소

 - 공개 데이터에서 조류 종과 영상 수가 제한적일 수 있음
 - 작은 조류는 LiDAR 점이 거의 없을 수 있음
 - RGB와 LiDAR calibration 오차가 거리 오차로 직접 전파됨
 - 인접 프레임 누수로 성능이 부풀려질 수 있음
 - WildDepth는 현재 pre-release 상태이므로 데이터 구조가 변경될 가능성이 있음

 따라서 최종 목표를 “모든 조류에 일반화”로 잡기보다는, 먼저 WildDepth에 포함된 plover/대형 조류 영상에서 metric distance estimation을 검증하는 것이 현실적입니다. 이후 실제 배포 대상 조류 데이터를
 추가하는 방향이 안전합니다.
