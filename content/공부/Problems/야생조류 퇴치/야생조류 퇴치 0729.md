# 장단점 비교
###### 엣지디바이스 + 카메라 센서·렌즈 방식의 장점
* 센서와 렌즈를 직접 선택해 **화각·초점거리·해상도·셔터 설정을 실험 목적에 맞게 구성**할 수 있음
* 압축 전 원본 프레임에 접근할 수 있어 **작은 새 탐지·종 분류·행동 분석에 유리**
* 자동 노출, Gain, 셔터 속도, 프레임레이트 등을 세밀하게 조절할 수 있음
###### 엣지디바이스 + 카메라 센서·렌즈 방식의 단점
* 카메라 위치마다 라즈베리파이, 전원, 저장장치, 방수함이 필요할 수 있음
* CSI 케이블이 짧아 **카메라와 라즈베리파이를 가까이 설치해야 함**
* 옥외 방수·결로·발열·냉각 설계가 필요함
* 여러 대를 설치하면 소프트웨어 업데이트, 시간 동기화, 재부팅 관리가 복잡해짐
* 원본 또는 고화질 영상을 직접 인코딩해야 해 엣지 디바이스 부하가 커질 수 있음
* 각 구역까지 별도 전원과 네트워크를 공급해야 하므로 배선과 유지보수가 PoE보다 복잡함
* 장기간 24시간 녹화에서는 일반 microSD의 수명과 파일 손상 문제가 발생할 수 있음
###### PoE 카메라 장점
* 랜 케이블 하나로 **전원과 영상 전송** 가능
* 최대 약 **100m 장거리 설치**에 유리
* 카메라 여러 대를 **중앙에서 관리**하기 쉬움
* 카메라 내부에서 H.264/H.265로 압축하여 전송하므로 **영상 인코딩 부담이 적고 Jetson의 처리 부하를 줄일 수 있음**
* 24시간 녹화와 다중 카메라 확장에 적합
* 각 구역에 220V 전원을 따로 설치하는 것보다 관리가 단순함
###### PoE 카메라 단점
* 압축 영상이라 작은 새의 세부 무늬가 손실될 수 있음
* 셔터, 노출, Gain 등 카메라 설정 자유도가 제한될 수 있음
* PoE 스위치, 옥외용 케이블, 방수 커넥터, 서지 보호기 등이 추가로 필요함
* 저가형 제품은 ONVIF·RTSP·수동 설정 지원 여부를 반드시 확인해야 함
    



# 결론: PoE 카메라가 좋음

### 구성도
```
                 4G/5G LTE망
                      │
              [유심 LTE/5G 공유기]
                      │ LAN
                [PoE 스위치]
          ┌───────────┼───────────┐
          │           │           │
     PoE 카메라들    NVR      옥외 Wi-Fi AP
          │           │           )))
       Baseline      HDD       Jetson A~D
       영상 촬영     로컬 저장   실험 장비
                                  │
                         카메라·스피커 로컬 제어
                                  │
                      LTE망을 통해 연구실 서버 통신
                      
```

옥외 Wi-Fi AP 및 젯슨은 추후 설치

### 옥외 ap 사용 이유
* 옥외 ap 사용을 안할 시 PoE 카메라 출력, lan 패스스루 지원 모델을 구매해야함. 
* Jetson은 Ethernet 포트로 직접 PoE 전원을 받을 수 없어 별도의 PoE 스플리터와 19V 변환장치가 필요함
* 카메라의 잔여 PoE 출력만으로 Jetson과 주변장치를 안정적으로 구동하기 어려움
* 옥외 RJ45 연결부와 변환장치가 늘어나 방수·결로·고장 관리가 복잡해짐

# 카메라 + PoE NVR

>**DORI 탐지 거리**는 ==CCTV나 보안 카메라의 식별력을 나타내는 표준 거리 기준==
>	**D (Detection, 발견):** 피사체의 존재 여부를 확인하는 단계
>	**O (Observation, 관찰):** 피사체의 특성(예: 사람의 행동이나 복장)을 알 수 있는 단계
>	**R (Recognition, 인지):** 피사체가 누구인지(아는 사람인지 등) 판단할 수 있는 단계
>	**I (Identification, 식별):** 법적 증거나 얼굴을 명확하게 구별할 수 있는 단계
>DORI 거리는 카메라와 피사체 사이의 거리를 의미하며, 감지 단계에서는 통상적으로 미터당 25픽셀
