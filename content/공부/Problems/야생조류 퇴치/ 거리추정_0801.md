- 왜 하지? 
	- 단순히 “새가 반응했다/사라졌다”만 보면 이동 거리, 방향, 속도 같은 세부 행동정보가 사라짐.
	- 단순히 `반응함 / 반응 안 함`만 보게되면, 
		- 한 마리는 0.5초 만에 빠르게 30m 도망감
		- 다른 한 마리는 3초 뒤 천천히 2m 이동함
	- 실제 반응 강도의 차이를 잃게 됨.
		- 거리측정을 기반으로 이동거리, 방향, 속도 추가적인 반응 시작 시간등을 가지고 
		  행동 변화에 대한 값, 반응 강도를 정량화해야함.
- 무엇을 알고 싶은가?
	- 자극 후 새가 얼마나, 어느 방향으로, 얼마나 빠르게 움직였는지를 알고 싶음. → 반응 강도

정량적인 반응 강도를 어떻게 만들 것인가
- 반응 시작까지 걸린 시간
- 화면상 이동량
- 이동 방향
- 이동 속도
- 가속도 변화
- 비행 시작 여부
- 체류시간
- 이탈 여부
- 날갯짓 빈도나 자세 변화
- 객체 크기 변화
- 일정 영역에서 벗어나는 데 걸린 시간

- 왜 거리추정이 필요한가?
	- 2D 영상의 픽셀 이동만으로는 수평·수직 이동인지, 실제 깊이(Z축) 방향으로 접근·후퇴한 것인지 구분하기 어려움. 
- 무엇을 할 것인가?
	- 카메라/렌즈/캘리브레이션과 객체의 픽셀 크기를 확인하고, 앉아 있는 새와 비행 중인 새를 나눠서 BBox / Segmentation / Keypoint / Scene Geometry 등을 이용해 Depth를 추정.
- 무엇을 검증할 것인가?
	- 거리추정이 어디까지 가능한지 / 어떤 상황에서 가능한지 / 어떤 종에서 가능한지 / 어느 정도 정확한지 확인.
- 거리추정 후에는?
	- 시간에 따른 거리 변화를 이용해 이동거리, 접근·후퇴 방향, 속도, 반응시간 등의 행동 속성값을 만듦.
- 결과의 의미는? 
	- AI가 단순히 “반응했다”가 아니라 “얼마나 강하게 회피했는가”를 세부 행동값을 이용해 추론할 수 있게 하는 것.


---

- **연구 목적**
    - 퇴치 자극에 대한 조류의 **적응·습관화를 줄이는 것**이 핵심
    - 이를 검증하려면 단순 방제 성공 여부가 아니라 **반응 강도의 변화**를 정량적으로 봐야 함
- **기존 평가지표의 역할**
    - 상용 퇴치장치와 WCD 비교
    - WCD 자체의 방제 성능 입증
    - 과실 피해율
    - 30초 이내 이탈 성공률
    - 체류시간
    - 재진입 시간
    - 최소 접근거리
    - 소음·비용 효율 등
- **기존 지표의 한계**
    - “퇴치가 되었는가”는 평가 가능
    - 반복 노출에 따라
        - 얼마나 늦게 반응하는지
        - 얼마나 덜 도망가는지
        - 얼마나 빨리 정상 행동으로 복귀하는지
        - 반응 강도가 얼마나 감소하는지
    - 이러한 **습관화 과정 자체를 세밀하게 설명하기에는 부족**
- **정량 지표가 필요한 이유**
    - 자극 직후 조류의 행동 반응 강도를 수치화
    - 반복 노출에 따른 반응 강도 변화 추적
    - 습관화·적응 여부 평가
    - 동일한 지표를 이용해 WCD와 상용장치 비교 가능
    - 최종적으로 방제 성능의 차이가 **어떤 행동 반응 차이에서 발생했는지 설명 가능**
- **행동분류**
    - VLM 활용 예정
    - 예:
        - 먹이활동
        - 경계
        - 걷기
        - 비행
        - 날갯짓
        - 휴식 등
- **재진입 판정**
    - 카메라 밖으로 나간 이후 동일 개체 Re-ID는 현실적으로 어려움
    - **15분 이내 동일 종 + 동일 개체수**가 다시 관측되면 동일 개체 또는 동일 군집의 재출현으로 운영적 판정
    - 엄밀한 개체 재식별이 아니라 `Estimated Reappearance`로 처리
- **거리추정 없이 얻을 수 있는 주요 정량 지표**
    - Behavior state
    - Response occurrence
    - Reaction latency
        - 자극 → 최초 행동 변화
    - Flight initiation
    - Flight initiation latency
        - 자극 → 비행 시작
    - ROI/FOV exit latency
        - 자극 → 영역 이탈
    - Vigilance duration
    - Feeding resumption latency
        - 자극 → 먹이활동 재개
    - Pixel displacement
    - Pixel velocity
    - 2D trajectory direction
    - ROI dwell time
    - Estimated reappearance latency
- **여러 자극 이벤트를 모아 산출 가능한 지표**
    - Response Rate
    - Flight Rate
    - 30 s Exit Rate
    - Estimated Reappearance Rate
    - 평균/중앙 Reaction latency
    - 평균 Flight initiation latency
    - 평균 Pixel velocity
    - 평균 Feeding resumption latency
    - 평균 Vigilance duration
- **습관화 평가**
    - 누적 노출 횟수에 따른 지표 변화 추적
    - 습관화가 진행될 경우 예상되는 변화
        - Reaction latency 증가
        - Flight Rate 감소
        - Exit Rate 감소
        - Pixel velocity 감소
        - Vigilance duration 감소
        - Feeding resumption latency 감소
        - Reappearance latency 감소
    - 즉,
        - 늦게 반응하고
        - 덜 도망가고
        - 약하게 움직이고
        - 더 빨리 원래 행동으로 복귀하는 방향
- **거리추정이 필요한 이유**
    - 영상 기반 상대값을 실제 물리량으로 변환
    - Pixel 이동량 → 실제 이동거리 mm
    - Pixel 속도 → 실제 속도 m/sm/s
    - 2D 이동 → 실제 공간 이동
    - 단순 화면 이탈 → 실제 방제구역 이탈
    - 자극원과의 실제 거리 변화 측정
    - 서로 다른 초기 거리에서 관측된 개체의 반응을 공정하게 비교
- **거리추정이 가능할 때 추가로 기대할 수 있는 지표**
    - **Actual Escape Distance**
        - 자극 이후 실제 이동거리 mm
    - **Mean Escape Velocity**
        - 평균 도피속도 m/sm/s
    - **Maximum Escape Velocity**
        - 최대 도피속도 m/sm/s
    - **Depth Change**
        - 자극 전후 깊이 변화
    - **Stimulus-distance Change**
        - 자극원에서 실제로 얼마나 멀어졌는지
    - **Distance Increase Rate**
        - 자극원으로부터 멀어지는 속도
    - **3D Escape Direction**
        - 자극원 기준 실제 도피 방향
    - **3D Trajectory**
        - 실제 공간상의 이동 경로
    - **Physical Zone Exit**
        - 실제 방제구역 이탈 여부
    - **Physical Zone Exit Latency**
        - 실제 방제구역을 벗어나는 데 걸린 시간
    - **Minimum Distance to Stimulus**
        - 자극원에 가장 가까이 접근한 거리
    - **Post-stimulus Distance**
        - 자극 후 5초, 10초, 15초 시점의 자극원과의 거리
    - **Physical Dwell Time**
        - 실제 방제구역 내부 체류시간
- **거리추정까지 포함한 습관화 평가**
    - 반복 노출에 따라
        - 실제 도피거리 감소
        - 실제 도피속도 감소
        - 자극원으로부터 멀어지는 거리 감소
        - 실제 방제구역 이탈률 감소
        - 방제구역 이탈시간 증가
        - 자극원에 더 가까운 거리까지 접근
    - 이러한 변화까지 포함하면 습관화를 더 직접적으로 설명 가능
- **최종 기술 구조**
    - VLM 행동분류
    - Detection / Tracking
    - 자극 로그–영상 시간 동기화
    - 재진입 운영 판정
    - 거리추정
    - Scene Calibration
    - 반복 노출 기반 통계 분석
- **전체 연구 흐름**
    - 퇴치 자극
    - → 행동분류 및 Tracking
    - → 거리 없는 행동 반응 정량화
    - → 반복 노출별 변화 분석
    - → 습관화 평가
    - → 거리추정 추가
    - → 실제 이동거리·속도·자극원 거리·방제구역 이탈로 확장
    - → 거리정보가 습관화 및 방제 효과 설명력을 얼마나 높이는지 검증
