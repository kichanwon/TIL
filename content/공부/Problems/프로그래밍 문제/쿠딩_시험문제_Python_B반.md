## 4번. 반별 점수 등급 분류하기

` #2차원리스트 , #중첩반복문 , #조건문 , #카운트`

### 문제
2개 반, 각 반에 3명의 학생이 있다.  
각 학생의 점수가 순서대로 주어진다.

점수를 다음 기준에 따라 분류하시오.

| 점수 범위         | 등급  |
| ------------- | --- |
| 80점 이상        | A   |
| 60점 이상 80점 미만 | B   |
| 60점 미만        | C   |

전체 학생 중 A, B, C 등급 학생 수를 각각 출력하시오.

### 입력 형식
첫 번째 줄에는 1반 학생 3명의 점수가 주어진다.  
두 번째 줄에는 2반 학생 3명의 점수가 주어진다.

### 출력 형식
첫 번째 줄에 A 등급 학생 수를 출력한다.  
두 번째 줄에 B 등급 학생 수를 출력한다.  
세 번째 줄에 C 등급 학생 수를 출력한다.

### 제한
```text
점수는 0 이상 100 이하의 정수이다.
입력은 2줄이며, 각 줄에는 점수 3개가 주어진다.
```

Python에서는 점수를 2차원 리스트에 저장한 뒤 처리하시오.

예시 구조는 다음과 같다.

```python
scores[class_index][student_index]
```

## 5번. 3일간 반별 온도 상태 분석하기

` #3차원리스트 , #삼중반복문 , #조건문 , #카운트`

### 문제
2개 반에서 3일 동안 측정한 실내 온도가 주어진다.  
각 반은 하루에 오전, 오후 두 번 온도를 측정한다.

즉, 데이터는 다음과 같은 구조이다.

```text
2개 반 × 3일 × 2회 측정
```

온도를 다음 기준으로 분류한다.

| 온도 범위 | 상태 |
|---|---|
| 30 이상 | HOT |
| 20 이상 30 미만 | NORMAL |
| 20 미만 | COLD |

전체 측정값 중 `HOT`, `NORMAL`, `COLD`의 개수를 각각 출력하시오.

### 입력 형식
총 6줄이 주어진다.  
각 줄에는 오전, 오후 온도 2개가 공백으로 구분되어 주어진다.

입력 순서는 다음과 같다.

```text
1반 1일차
1반 2일차
1반 3일차
2반 1일차
2반 2일차
2반 3일차
```

### 출력 형식
첫 번째 줄에 `HOT`의 개수를 출력한다.  
두 번째 줄에 `NORMAL`의 개수를 출력한다.  
세 번째 줄에 `COLD`의 개수를 출력한다.

### 제한
```text
온도는 0 이상 100 이하의 정수이다.
입력은 6줄이며, 각 줄에는 온도 2개가 주어진다.
```

### 요구사항
Python에서는 데이터를 3차원 리스트에 저장한 뒤 처리하시오.

예시 구조는 다음과 같다.

```python
temperatures[class_index][day_index][time_index]
```
