## 4번. 상품 판매 등급 분류하기

` #2차원리스트 , #중첩반복문 , #조건문 , #카운트`

### 문제
2개 매장에서 각각 4개의 상품 판매량이 주어진다.  
각 판매량을 다음 기준으로 분류한다.

| 판매량 | 등급 |
|---|---|
| 50 이상 | HIGH |
| 20 이상 50 미만 | MIDDLE |
| 20 미만 | LOW |

전체 상품 중 `HIGH`, `MIDDLE`, `LOW`에 해당하는 상품 개수를 각각 출력하시오.

### 입력 형식
첫 번째 줄에는 1번 매장의 상품 4개 판매량이 주어진다.  
두 번째 줄에는 2번 매장의 상품 4개 판매량이 주어진다.

### 출력 형식
첫 번째 줄에 `HIGH`의 개수를 출력한다.  
두 번째 줄에 `MIDDLE`의 개수를 출력한다.  
세 번째 줄에 `LOW`의 개수를 출력한다.

### 제한
```text
판매량은 0 이상 100 이하의 정수이다.
입력은 2줄이며, 각 줄에는 판매량 4개가 주어진다.
```

### 요구사항
Python에서는 판매량을 2차원 리스트에 저장한 뒤 처리하시오.

예시 구조는 다음과 같다.

```python
sales[store_index][product_index]
```

## 5번. 3차원 리스트로 작물 생육 상태 분류하기

` #3차원리스트 , #삼중반복문 , #조건문 , #카운트`

### 문제
2개의 인큐베이터에서 3일 동안 작물의 생장 길이를 측정하였다.  
각 인큐베이터는 하루에 오전, 오후 두 번 측정한다.

즉, 데이터 구조는 다음과 같다.

```text
2개 인큐베이터 × 3일 × 2회 측정
```

생장 길이를 다음 기준으로 분류한다.

| 생장 길이 | 상태 |
|---|---|
| 15 이상 | GOOD |
| 8 이상 15 미만 | NORMAL |
| 8 미만 | POOR |

전체 측정값 중 `GOOD`, `NORMAL`, `POOR`의 개수를 각각 출력하시오.

### 입력 형식
총 6줄이 주어진다.  
각 줄에는 오전, 오후 생장 길이 2개가 공백으로 구분되어 주어진다.

입력 순서는 다음과 같다.

```text
1번 인큐베이터 1일차
1번 인큐베이터 2일차
1번 인큐베이터 3일차
2번 인큐베이터 1일차
2번 인큐베이터 2일차
2번 인큐베이터 3일차
```

### 출력 형식
첫 번째 줄에 `GOOD`의 개수를 출력한다.  
두 번째 줄에 `NORMAL`의 개수를 출력한다.  
세 번째 줄에 `POOR`의 개수를 출력한다.

### 제한
```text
생장 길이는 0 이상 100 이하의 정수이다.
입력은 6줄이며, 각 줄에는 생장 길이 2개가 주어진다.
```

### 요구사항
Python에서는 데이터를 3차원 리스트에 저장한 뒤 처리하시오.

예시 구조는 다음과 같다.

```python
growth[incubator_index][day_index][time_index]
```
